# KOSIS 여성 복지 시계열 통계표 목록

- 출처: KOSIS 국가통계포털 OpenAPI (`https://kosis.kr/openapi/`)
- 인증: `apiKey` 쿼리 파라미터 (`.env.local`의 `KOSIS_API_KEY`)
- 2026-10-22에 실제로 호출해서 확인했다. 아래 표는 모두 메타 조회와 데이터 조회가 성공한 것만 실었다.

## API 사용법

| 용도           | 요청                                                                                                                       |
| -------------- | -------------------------------------------------------------------------------------------------------------------------- |
| 통계표 검색    | `statisticsSearch.do?method=getList&searchNm=<검색어>&resultCount=30`                                                      |
| 항목·분류 메타 | `statisticsData.do?method=getMeta&type=ITM&orgId=<기관>&tblId=<표>`                                                        |
| 수록 기간 메타 | `statisticsData.do?method=getMeta&type=PRD&orgId=<기관>&tblId=<표>`                                                        |
| 데이터         | `Param/statisticsParameterData.do?method=getList&orgId=&tblId=&itmId=ALL&objL1=ALL…&prdSe=Y&startPrdDe=2014&endPrdDe=2025` |

모든 요청에 `apiKey`, `format=json`, `jsonVD=Y`를 붙인다.

- `objL1`~`objLn`은 표의 분류 개수(아래 "분류" 열의 개수)만큼 `ALL`로 채운다.
- `prdSe`: 년 `Y`, 반기 `H`, 분기 `Q`, 월 `M`, 3년 주기 실태조사 `F`.
- 기간은 `startPrdDe`/`endPrdDe`로 지정하거나, 최근 N개 시점만 받으려면 `newEstPrdCnt=N`을 쓴다.
- 응답 한 행이 셀 하나다: `PRD_DE`(시점), `ITM_NM`(항목), `C1_NM`·`C2_NM`…(분류값), `DT`(값), `UNIT_NM`(단위).
- 이 개발 환경에서는 Python `urllib`이 KOSIS 인증서 체인을 신뢰하지 못한다. curl은 정상 동작한다.

```bash
# 예: 연령대별 경력단절여성 2014~2025
curl "https://kosis.kr/openapi/Param/statisticsParameterData.do?method=getList&apiKey=$KOSIS_API_KEY&format=json&jsonVD=Y&orgId=101&tblId=DT_1ES4H06J&itmId=ALL&objL1=ALL&prdSe=Y&startPrdDe=2014&endPrdDe=2025"
```

## 분석 시 주의

- 경력단절여성 표는 `…J`(2025년까지)와 `…S`(2024년까지) 두 계열이 있다. 서로 기준이 다른 별도 계열로 보이니 한 분석 안에서는 섞지 않는다.
- 경력단절여성 수가 줄어든 것은 15–54세 기혼여성 자체가 줄어든 영향도 받는다. 같은 표의 기혼여성 수로 나눈 비율로 비교하는 것이 낫다.
- 성평등가족부 실태조사 표(기관 154)는 3년 주기라 시점이 3개 안팎이다. 연간 추세는 국가데이터처 표로 보고, 실태조사는 원인·특성 보조 자료로 쓴다.
- 더 찾을 때는 검색 API에 `경력단절여성`, `한부모`, `육아휴직`, `맞벌이 가구`, `성별 상대빈곤율` 같은 검색어를 넣으면 관련 표가 나온다.
